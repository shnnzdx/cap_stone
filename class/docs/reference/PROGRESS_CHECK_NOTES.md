## 60-second version

My capstone project focuses on reducing low-value backend monitoring alerts without hiding real incidents. For Milestone 1, I decided to focus on the front-end experience first so I can clearly show the product direction. The current prototype includes:

- a dashboard-style overview of the project and milestone status
- a simulated alert review queue
- a selected alert detail panel with explanation and confidence score
- a feedback section where users can label alerts as useful, noisy, duplicate, expected, false positive, or real incident
- an admin preview for governance and approval flow

I am using AI tools to help generate front-end structure faster, compare component options, and refine the UI and wording. At the same time, AI is helping my learning because I ask it to explain why certain layout or state-management decisions make sense, so I can understand and extend the code myself.
