# cap_stone

Milestone 1 front-end demo for the capstone project:
Human-in-the-Loop Adaptive Alert Noise Reduction System for Backend Reliability Monitoring.

## What is in this repo

- `1/`: course and proposal documents
- `src/`: React front-end demo
- `package.json`: front-end scripts and dependencies

## Front-end demo scope

This demo is intentionally small and presentation-ready. It shows:

- a project overview and milestone progress snapshot
- a simulated alert review queue
- an alert detail and feedback panel
- an admin-side preview for thresholds, suppression, and approval flow
- a short section explaining how AI tools support the project and learning

## Run locally

1. Install dependencies with `pnpm install`
2. Start the dev server with `pnpm dev`
3. Build with `pnpm build`

## Progress-check talking points

- Current milestone progress:
  a React front-end prototype with realistic alert review and admin workflow screens
- How AI tools are being used:
  AI helps scaffold UI structure, suggest component patterns, refine copy, and accelerate iteration
- How AI supports learning:
  AI explanations are used to understand component composition, state flow, and front-end tradeoffs rather than only copying code
